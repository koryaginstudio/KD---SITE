# КОРЯГИН ДИЗАЙН™

Рабочий проект сайта и закрытой панели управления портфолио. Клиентская часть
работает на React/Vinext, проекты и фотографии хранятся в Supabase.

## Основные разделы

- `/` - основной сайт;
- `/portfolio` - все проекты;
- `/admin` - закрытая панель управления проектами и типами работ;
- `/api/admin` - серверный интерфейс панели управления.

## Структура

- `app/` - маршруты, серверная логика и админ-панель;
- `public/assets/fonts/` - используемые шрифты;
- `public/assets/images/` - фотографии и графика основных страниц;
- `public/assets/logos/` - используемые версии логотипа;
- `public/assets/portfolio/` - резервные обложки проектов;
- `public/assets/video/` - используемые видео;
- `supabase/` - актуальная схема портфолио.

Файлы `dist/`, `node_modules/`, `.sites-runtime/` и `.wrangler/` создаются
автоматически и не входят в исходники проекта.

## Запуск

- `npm ci` - установить зависимости;
- `npm run dev` - запустить локальную разработку;
- `npm run build` - собрать проект;
- `npm test` - собрать проект и проверить HTML-оболочку.

## Авторизация панели

Панель использует защищённый вход ChatGPT/Sites. Доступ разрешён владельцу,
а операции с Supabase выполняются только на сервере с секретным ключом из
окружения хостинга.
